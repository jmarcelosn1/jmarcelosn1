## Como trabalho com agentes de IA

1. **Especificação primeiro.** Regras do cliente e decisões de design ficam versionadas no repositório (`CLAUDE.md`, `AGENTS.md`, `docs/specs`), para o agente não reabrir o que já foi decidido.
2. **O agente executa, eu confiro.** Cada entrega passa por checagem de tipos, build e, quando existe, a esteira de testes, além de conferência no navegador.
3. **Sem afirmar o que não foi verificado.** Testes, publicação e métricas só entram na documentação quando há evidência.
